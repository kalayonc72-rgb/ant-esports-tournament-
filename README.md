# ANT ESPORTS Tournament Website — Starter

A beginner-friendly responsive website starter with a black-and-yellow ANT ESPORTS theme.

## Included
- `index.html` — page and squad registration fields
- `style.css` — responsive black/yellow design
- `script.js` — demo form behavior

## Important
The registration form is currently a visual/demo form. It does **not** send or save registrations. Before using it for a real tournament, connect it to Google Forms, Google Sheets via Apps Script, or a backend/database. Do not collect real player information with the demo form.

## Preview
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in Chrome, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a Public GitHub repository named `ant-esports-tournament`.
2. Upload all three files (`index.html`, `style.css`, `script.js`) to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. After publishing, the URL will look like `https://YOUR-USERNAME.github.io/ant-esports-tournament/`.

## Customize before launch
Update tournament date/time, entry fee, prize pool, rules, organizer contact details, and connect the form to a real submission destination.
